# Présentations

Les présentations sont publiées ici au fur et à mesure que le matériel de chaque
séance devient disponible.

---

## Où les trouver

Une présentation appartient à une séance : ses boutons de téléchargement
s'affichent sur la page du jour, juste sous la séance qu'elle accompagne.

[Jour 1](../day1/index.md){ .md-button } [Jour 2](../day2/index.md){ .md-button }
[Jour 3](../day3/index.md){ .md-button } [Jour 4](../day4/index.md){ .md-button }
[Jour 5](../day5/index.md){ .md-button }

Chacune est proposée en anglais et en français, en PDF ou en PowerPoint, afin que
vous puissiez suivre la séance dans votre langue de travail et conserver le
fichier ensuite.

---

## Pendant l'atelier

Vous n'avez rien à télécharger à l'avance. Chaque laboratoire porte son propre
matériel dans le notebook qui vous sera fourni.

Si une présentation dont vous avez besoin ne figure pas ici le jour venu,
demandez-la : l'équipe d'animation l'a.
